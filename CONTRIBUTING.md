# Adding a skill to the collection

This catalog separates **skills created here** from **curated links**. Keep author credit visible wherever a skill is mentioned.

## A skill created here

1. Add `skills/<short-name>/SKILL.md` with a clear name, purpose, prerequisites, and safe operating rules.
2. Add a concise README entry that links to that file and says what learning task it helps with.
3. Add a license for the skill and any original supporting assets before publishing it.
4. If the skill builds on outside work, name the source, link to it, state what changed, and preserve any required license notices.

## A curated third-party skill

Add a short original summary to the README. Include:

- The skill name and direct link to its source.
- Its creator, linked by name.
- The concrete language-learning task it helps with.
- Relevant prerequisites and any important limits you verified.
- A link to the upstream license, with the date checked.

Link to the upstream project for installation and current instructions. Do not copy its `SKILL.md`, scripts, screenshots, logo, or other assets into this catalog by default. If an upstream link moves, update the entry rather than preserving an uncredited copy.

## Editorial standard

Describe what a skill *does*, not just what it promises. Avoid claiming that a skill was tested with a particular Anki collection or agent unless that test actually happened. Keep safety descriptions faithful to the upstream documentation. If a skill can edit study data, say clearly when the user should inspect the proposed action.
